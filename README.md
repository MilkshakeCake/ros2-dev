# ROS 2 Systems Lab

A repository dedicated to solo practice of ROS 2 Foxy. This workspace explores the integration of Mechanical Systems logic with Computer Science fundamentals using both Python and C++.

## 🛠 Development Environment
- **OS:** Ubuntu 20.04 (WSL2 on Windows 11)
- **Processor:** AMD Ryzen 7 5800X
- **ROS Distro:** Foxy Fitzroy
- **Primary Languages:** C++ (ament_cmake), Python (ament_python)

## 📁 Workspace Structure
* `src/my_cool_robotics`: Python package featuring open-loop trajectory drivers.
* `src/cpp_test`: C++ package focused on high-performance node implementation.
